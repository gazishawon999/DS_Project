# 🚀 DATA_STRUCTURE (Practice Codes)

This repository contains my practical implementations of **Data Structures in C**, covering both **Array** and **Linked List** operations.

All codes are written as part of my **learning, practice, and academic assignments**, focusing on building strong problem-solving skills and understanding core data structure concepts.

---

## 📚 Features

This project includes a menu-driven program that allows performing multiple operations on data structures.

### 🔹 Array Operations

- ✅ Input Elements  
- ✅ Display Array  
- ✅ Insertion (Last Position)  
- ✅ Insertion (Specific Position)  
- ✅ Deletion (Specific Position)  
- ✅ Linear Search  
- ✅ Bubble Sort  
- ✅ Binary Search  

---

### 🔹 Linked List Operations

- ✅ Insertion (Last Node)  
- ✅ Insertion (Specific Position)  
- ✅ Deletion (Specific Position)  
- ✅ Display Linked List  
- ✅ Count Total Nodes  
- ✅ Linear Search  

---

## 📂 Code Structure

The implementation is divided into:

- `Main Program` → Menu-driven interaction  
- `Array Functions` → All array-related operations  
- `Linked List Functions` → Dynamic memory-based operations  

---

## 🧠 Concepts Used

- 📌 Static Array Handling  
- 📌 Dynamic Memory Allocation (`malloc`, `free`)  
- 📌 Pointer Manipulation  
- 📌 Searching Algorithms  
- 📌 Sorting Algorithms  
- 📌 Structured Programming

   ```bash

   ```

   ```bash
   ./program
   ```

## ⚠️ Notes

- Array indexing in this program starts from **1 instead of 0**  
- Binary Search automatically sorts the array before searching  
- The program uses a **fixed size array (max 100 elements)**
